# Expense & Budget Visualizer

A responsive, client-side single-page application for tracking daily expenses and visualizing spending by category.

## Features

- Add and delete expense transactions
- Organize spending by category (default + custom categories)
- Pie chart visualization of spending distribution
- Monthly summary with per-category breakdown
- Light / dark mode toggle
- All data persisted in browser `localStorage`

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- [Chart.js v4](https://www.chartjs.org/) via CDN

## Usage

Open `index.html` directly in a browser, or serve the project root with any static file server (e.g. GitHub Pages, `npx serve .`). No build step required.
